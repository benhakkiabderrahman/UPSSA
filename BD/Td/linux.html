الجزء الأول: أساسيات نظام التشغيل Linux

1. ما هو نظام التشغيل Operating System؟

Section 1.1

نظام التشغيل Operating System (OS) هو مجموعة من البرامج التي تدير موارد الحاسوب Hardware، وتوفر الخدمات اللازمة للتطبيقات والمستخدمين. بمعنى بسيط: عندما نفتح برنامجاً أو نحفظ ملفاً أو نستعمل لوحة المفاتيح، فإن نظام التشغيل يتولى تنظيم هذه العمليات والتواصل مع العتاد.

البنية العامة للحاسوب (Computer System Layers)
Users
المستخدمون
Applications
Firefox WhatsApp Text Editor
System Calls
Operating System (OS / Kernel)
إدارة الموارد وتوفير الخدمات
Hardware
CPU RAM Disk Keyboard Screen
أمثلة على أنظمة التشغيل: Windows macOS Unix Linux Android
ملاحظة تقنية — System Calls

في Unix/Linux تتواصل البرامج مع النظام من خلال System Calls وهي طلبات خدمات يرسلها البرنامج إلى النواة Kernel.

2. الأدوار الأساسية لنظام التشغيل

Section 1.2

يؤدي OS ثلاثة أدوار رئيسية:

الدور (Rôle) الشرح مثال عملي
Translator يحول طلبات البرامج إلى عمليات على Hardware حفظ ملف على Disk
Chef d'orchestre ينظم توزيع الموارد بين البرامج تشغيل Video مع Download في نفس الوقت
Security Agent يمنع الوصول غير المسموح إلى الموارد منع تطبيق من استعمال Camera دون إذن
مثال توضيحي: عندما تشاهد فيديو وتحمل ملفاً في الوقت نفسه
  • OS ينظم استعمال CPU بين البرنامجين.
  • OS يدير Memory الخاصة بهما.
  • OS ينظم الكتابة على Disk.
  • OS يتحكم في الوصول إلى الأجهزة الطرفية.

3. المهام الخمس لنظام التشغيل

إدارة البرامج قيد التنفيذ وتوزيع CPU بينها 1. Process Management
تخصيص RAM للبرامج واسترجاعها عند الانتهاء 2. Memory Management
تنظيم الملفات والمجلدات والتحكم في الصلاحيات 3. File Management
إدارة التواصل مع الأجهزة عبر Drivers 4. I/O Management
معالجة الأخطاء والمشاكل والـ Interruptions 5. Exception Management

الهدف من هذه المهام هو تقاسم موارد الحاسوب وتحسين استعمالها.

1. Ergonomics

سهولة الاستعمال وتوحيد طريقة التعامل مع الموارد.

2. Efficiency

استغلال CPU و RAM و Disk بكفاءة عالية.

3. Scalability / Evolutivity

القدرة على التكيف مع Hardware جديد ومتطلبات متزايدة.

14. المسارات Absolute Path و Relative Path & 15. أوامر التنقل Navigation

Absolute Path (المسار المطلق)

يبدأ دائماً من الجذر /، ولا يعتمد على مكانك الحالي. مثال: /home/student/TP/TP1

Relative Path (المسار النسبي)

يبدأ من المجلد الحالي Current Directory ولا يبدأ بـ /. مثال: ../TP2 أو ./TP1

20. الروابط Links (ln)

اسم إضافي يشير مباشرة إلى نفس الـ Inode. إذا حُذف الاسم الأصلي، يبقى الـ Hard Link صالحاً ويحتفظ بالبيانات.

رابط رمزي يشير إلى مسار ملف آخر. إذا حُذف الملف الأصلي يصبح الرابط معطلاً (Broken Link).

33. تغيير Permissions باستخدام chmod (Symbolic & Octal)

A. الطريقة الرمزية Symbolic Notation

الصيغة: chmod [u/g/o/a] [+/-/=] [r/w/x] file

إضافة Execute للمالكchmod u+x script.sh
إزالة Write من المجموعةchmod g-w file.txt
تحديد Read فقط للآخرينchmod o=r file.txt
إعطاء Read و Write للجميعchmod a+rw file.txt

B. الطريقة الرقمية Octal Notation (r=4, w=2, x=1)

OctalBinaryPermissions
